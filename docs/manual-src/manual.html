日拾是什么

WHAT IT IS

日拾是一个「一天一页」的小本子。它不做复杂的项目管理，只做三件事：把今天要做的事写清楚、做完打勾、晚上留几句话（和一两张照片）给自己。写着写着，日历会攒下你走过的每一天。

四个页面

今天：一天的任务清单，按时间排成一条时间线，点圆圈勾选完成；最下面是今日复盘。

时间轴：填了截止日期的任务，自动按日期串成倒计时。

小记：突然想到的点子、随手要记的小事。

日历：每个月的完成情况、心情、星星和照片标记。

两个藏起来的入口

齿轮（右上角）：账号与同步、提醒、导出备份。

图钉（「今天」页右上角）：每周固定任务。比如「周一到周五 7:30 背单词」，设一次，每天自动出现。

它和别的待办 App 有什么不同

  • 一天一页，而不是一条长长的清单。没做完的事不会永远堆在列表顶端 —— 今天做几件，你说了算。
  • 固定任务和临时任务分得清。课表、健身这种每周重复的，改一次只影响以后；某一天请假就「只改这一天」，历史记录不会变。
  • 它记得你的心情和画面。每晚复盘选一个表情、放一两张照片，日历上就能看到这个月哪几天是笑着过的。
  • 不用装 App。浏览器打开、添加到主屏幕，和原生 App 一样用；断网也能写，联网自动同步。
不注册也能用。不登录时数据只存在这台设备上；登录后才在 iPhone / iPad / Mac 之间同步。不妨先随便用两天，觉得顺手了再登录。

五分钟上手

QUICK START
  1. 把它放到桌面上。iPhone / iPad：用 Safari 打开网址 → 底部「分享」→ 往下找「添加到主屏幕」→ 添加。Mac：Safari 菜单「文件 → 添加到程序坞」，或 Chrome 地址栏右侧的「安装」图标。Windows / 安卓：Chrome 右上角菜单 →「安装应用」或「添加到主屏幕」。
  2. 从桌面图标打开它。之后每次都从图标进，而不是从浏览器书签进 —— 只有这样才能开启推送、全屏显示。
  3. （可选）登录账号。齿轮 →「账号与同步」→ 填邮箱和密码（至少 6 位）→「注册新账号」。已有账号就点「登录」。登录后，其它设备填同样的邮箱密码就能看到同一份数据。
  4. 写下今天的第一件事。「今天」页 →「添加这一天的任务」→ 输入任务名 → 需要就填开始和结束时间 → 右上角「保存」。
  5. 做完点一下圆圈。圆圈变成勾，任务变淡，顶部进度条往前走。点错了再点一次就取消。
第一次打开时请允许通知。系统会问「日拾 想要发送通知」，点「允许」，这样每天 07:30 和 23:00 的提醒才收得到。当时点了「不允许」也没关系，之后可以在 iPhone「设置 → 通知 → 日拾」里打开。

登录之后，建议顺手做的两件事

① 开启准点推送

齿轮 →「提醒」→「开启准点推送」→ 允许通知。每台设备各开一次。开了之后，即使 App 完全关闭也会在 07:30 / 23:00 准时收到提醒（详见第 10 章）。

② 建一条固定任务

「今天」页右上角点图钉 → 右下角「＋」→ 比如「周一到周五 07:40 背单词」，选好星期和时间，保存。以后每天自动出现。

3

「今天」：一天的主页面

TODAY

打开日拾看到的就是这一页。它只回答一个问题：今天要做什么，做到哪儿了。

从头到尾看一遍

位置说明
切换日期标题两边的 ‹ › 是前一天 / 后一天；直接点「今天」这两个字会弹出日期选择器，可以跳到很久以前或以后。不是今天时，下方会多一个「↩ 回到今天」。
任务顺序自动按开始时间排：早的事在上面。没填时间的排在最后，保持你写的顺序。
打勾点左边的圆圈，或直接点任务文字，都能标记完成。圆圈打勾时会轻轻震动一下。
进度列表上方显示「已完成 2/5」，下面一条细线随之变长。
图钉标记任务名前面带图钉的是每周固定任务。点它的文字不会打勾，而是弹出这一天的操作菜单（见第 5 章）。
时间有开始时间的显示成「08:30」，有结束时间时下面再跟一个较淡的时间，像「08:30 ~09:15」。

页面上的另外几条横条

截止提醒条

今天起 7 天内有任务要截止时，页面顶部会出现一条提醒，写着任务名和「还有 3 天」。点一下直接跳到时间轴。

休息日

某天不想做固定任务（出去玩、生病），点页面底部的「设为休息日」，这天的固定任务全部跳过。取消就点「取消休息」。

页面底部的小字

如果这天跳过了某些固定任务，底部会写「这天跳过了 2 个固定任务」，后面跟着「恢复「背单词」」这样的链接，点一下就能恢复，不用回固定任务页。

最下面是今日复盘。今天和过去的日子都有，可以选心情、写几句话、放几张照片，写完自动保存；未来的日子不显示（还没过，没什么可复盘的）。详见第 8 章。
空白的页面不是出错。这天还没有任务时，会看到一只兔子说「这一页还是空白的～」，点下面的按钮就能开始写。

「编辑任务」：一次写完整天

EDIT A DAY

在「今天」页点「编辑这一天的任务」就进来了。一行一个任务，像在纸上列清单一样。

  1. 输入任务内容。每一行上面是任务名（最多 80 个字）。
  2. 按回车，自动多一行。在任务名输入框里敲回车，光标会跳到下一行，可以一路写下去，不用一直点「添加一行」。
  3. 填时间（可以不填）。每行下面有「开始 至 结束」两个时间框。只填开始也行，只填结束也行，都不填也行 —— 不填的排在当天最后。
  4. 保存。右上角或页面底部的「保存」都可以，两处效果一样。

删除 vs 跳过

右边的 ✕ 有两种意思：普通任务＝删掉这一行，保存后就不见了；固定任务＝只是「这一天跳过」，每周安排不受影响。想彻底取消这项固定任务，要去图钉页面里停掉或删除。

这里的修改只影响这一天

带图钉的任务，在这一页改名字、改时间，只对这一天生效，旁边会提示「每周固定 · 这里改只影响这一天」。改过的日子会记住「今日已调整」，以后其它日子还是原来的样子。

小窍门：早上一次把一天写完（包括「晚上跑步」这种），白天就只看「今天」页打勾，不再反复改清单 —— 改清单最耗神。
5

每周固定任务

WEEKLY ROUTINES

课表、背单词、健身、每周一次的例会 —— 这类「每周都会重复」的事，不必每天手动写，交给「每周固定」。入口在「今天」页右上角的图钉，页面按周一 → 周日分组，每项写着时间、星期和有效期。

新建一条固定任务

  1. 任务名，比如「背 50 个雅思单词」。
  2. 每周哪几天：点星期几的小方块，可以多选。下面有快捷键：「工作日」「周一至周六」「每天」「周末」。
  3. 开始 / 结束时间：决定它出现在当天时间线的哪个位置。不填就排在最后。
  4. 从哪天开始：默认今天。到哪天：不填就是长期一直重复；填了到期自动结束，收进「已结束」里。
  5. 保存。以后每个匹配的日子，「今天」页都会自动多出这一项。

四种「改」的方式，别用错

在「今天」页点一条固定任务的名字，会弹出菜单，每一行对应一种改法：

菜单项影响范围什么时候用
标记完成只有这一天做完了，等于打勾。
只改这一天只有这一天今天这门课换到 10 点、今天任务改成「复习」，但下周照旧。
修改以后的每周安排从今天起往后所有日子课表变了、时间永久调整。以前的记录不受影响，旧日子仍是原来的样子。
这一天跳过只有这一天今天请假、出去玩。页面底部可一键恢复。
从这天起不再安排从今天起往后这门课结束了。以前做过的记录会保留，能在「已结束」里查看。

还有两个实用功能

暂停一段时间

在固定任务页点开一条任务，编辑时有「暂停一段时间」：填「从」和「到」，这期间它不出现，但不算结束，到日子自动恢复。适合考试周、寒假。

填了「从」不填「到」＝从那天起一直暂停，想恢复时点「清除暂停」。

停止 vs 彻底删除

从今天起停止：不再安排，但过去每天的完成记录都留着 —— 想回顾「这学期背了多少天单词」就靠它。

彻底删除：连以前的记录一起删掉，不可恢复。建议默认用「停止」。

改了每周安排，历史不会跟着变。这是故意的：过去的日子应该保持你当时真实的样子。所以只想改某一天，请用菜单里的「只改这一天」，不要用「修改以后的每周安排」。

时间轴：截止日期与倒计时

DEADLINES

有些事不属于某一天，而是「某天之前必须交」：论文、考试、报名、还书。这类事放进时间轴。

  1. 底部第二个按钮进「时间轴」。
  2. 上面填任务名称（如「雅思考试」）和截止日期（默认填好一周后，可改）。
  3. 点「＋ 添加」。它会自动插到时间线上正确的位置，按月份分组。

怎么看倒计时

徽章意思显示效果
今天今天截止最醒目，红色
N 天还有 N 天2 天以内偏红，7 天以内提醒色，更远是普通色
过了 N 天已过期还没勾变灰，提醒你处理或删掉
完成已勾选整条变淡，收进「已完成」里

完成与修改

点左边的圆圈标记完成；点任务名字打开修改窗口，可以改名字、改日期，或者删除。

自动提醒

截止前 7 天、5 天、2 天、当天，早上 07:30 的提醒里会带上它；「今天」页顶部也会出现一条提醒横条。

和「今天」的分工：「今天」页放着今天要动手做的事；时间轴放着「期限」。同一件事可以两边都有 —— 比如时间轴里有「12 月 20 日交毕业论文」，今天这页写「写文献综述 2 小时」。
7

日历：翻看走过的每一天

CALENDAR

底部第四个按钮。这里不是用来安排计划的，而是用来回头看的：这个月完成了多少、哪几天全部做完、心情怎么样、哪天留了照片。

它是倒着排的

月份从上往下越来越旧：最上面是本月（或最晚有任务的月份），往下滑是上个月、上上个月……正好符合「往回翻」的习惯。没有任务的月份会自动隐藏（本月除外），所以列表不会空荡荡地拉很长。

每一格小卡上有什么

  • 日期数字：今天那一格会高亮，标「今日」。
  • 当天任务：最多显示 3 条，已完成的带 √ 且更淡；超过 3 条显示「+2」。
  • ★ 小星星：这天的任务全部完成才会出现，是留给你自己的奖励。
  • 心情：这天写了复盘并选了心情，日期旁边会有一个小表情。
  • 📷 照片：这天的复盘放了照片，日期旁边会多一个小相机。点进去就能看。新
  • 未来日期：还没到、也还没安排任务的日子不显示；安排了任务才会出现，并标「明日任务」「后天」「5 天后」。
  • 每月标题：左边是月份和季节贴纸，右边写「完成 N 项」。
点任意一格会直接跳到那一天。想补记上周某天做过的事、或补写那天的复盘，从日历点进去最快。

本月完成数量

每月标题右边的「完成 37 项」是这个月所有勾掉的任务总数（含固定任务）。月底看一眼，比任何打卡 App 都直观。

连成一片的小星星

一片 ★ 连着的那几天，就是状态最好的时候。翻回去看看当时写了什么、拍了什么，往往能找到自己的节奏。

今日复盘：心情、三句话和照片

DAILY REVIEW

「今天」页任务列表下面那张信纸。它只有三个动作：选一个心情，写三句话，想的话再放几张照片。

① 选心情

超开心
不错
平静
有点累
低落

五种心情：超开心 / 不错 / 平静 / 有点累 / 低落。点一下选中，再点同一个可以取消；选中的心情会显示在日历上，一个月的心情分布一眼就能看出来。

② 写三件事

今天的感受有什么开心或难忘的小事。一句也行。
小错误 / 踩过的坑写下来就是进步。今天哪里绕了远路、忘了什么。
感想 / 想对明天的自己说留一句温柔的话，明天的你会看到。

边写边存

不用点保存。停手的一瞬间就存好了，右上角出现「已保存 ✓」。写着写着切走、关掉 App 都不会丢。

写长了也不挤

每格最多 2000 字。字多时只显示前几行，下面出现「展开全文」，点开看全部。

③ 放几张照片 v0.9 新增

今天吃到的好吃的、看到的晚霞、写满的笔记本 —— 配上一张照片，过几个月翻日历时会记得更清楚。

  1. 添加。在心情下面点「📷 添加照片」，从相册选或直接拍照。一次可以选好几张，每天最多 3 张；超出的会提示「每天最多 3 张」。
  2. 查看。点缩略图看大图，再点一下关闭。
  3. 删除。点缩略图右上角的 ×，确认后删除。云端的那一份也会一起删掉。

没网也能加

照片先存在这台设备上，马上就能看到；左下角会显示「☁︎ 待上传」。联网后自动上传，这个标记就会消失。

换台设备也能看

登录同一个账号，打开那天的复盘，照片会自动下载显示。之后就存在本机，再看不费流量。

不占地方

照片会在手机上先压缩，每张只有一两百 KB，原图不会被改动。

只有你能看到

照片存在按账号隔离的私密空间里，朋友用同一个日拾也看不到你的照片。

同一天的复盘，尽量只在一台设备上写。两台设备同时改同一天的复盘，会以最后保存的那次为准，另一边刚写的字或刚加的照片可能被覆盖。平时用一台写，就不会碰到。
23:00 的提醒会顺带提醒你写复盘。如果今天还有没做完的任务，提醒里会先列出来，再补一句「做完记得写写今日复盘哦」。
补写。过去的日子也能写、也能补照片。从日历点进某一天，往下滑就是那天的复盘 —— 想起来随时补，不会因为过了零点就写不了。
9

小记：灵感与随手记

QUICK NOTES

底部第三个按钮。它解决的是「现在不方便安排，但不想忘」的东西，分两种。

灵感

想法、点子、想做的事。记下来之后可以慢慢判断它值不值得做，状态一共五种。

待定 → 可行 → 已执行

也可以标「不可行，修改为…」（写下改后的版本）或「不可行，放弃」。任何时候都能「恢复为待定」，重新想一遍。

随手记

想起的小事，比如「买洗衣液」「问老师作业格式」。记完可以勾选完成 / 标为未完成，像一张便签。

两种都支持「安排到某一天的任务」，把它变成某天的正式任务。

怎么用这一页

  1. 顶部切换类型：点「灵感」或「随手记」，决定这条记成哪种。
  2. 写一句话（最多 500 字），点「记下来」。列表按时间倒序，最新的在最上面。
  3. 筛选：中间的「全部 / 灵感 / 随手记」切换大类；选灵感后再用下面的小标签分「待定·可行 / 已执行 / 已修改 / 已放弃 / 全部」。
  4. 点卡片打开菜单：改状态、安排到某一天、编辑文字、删除。
最有用的一条路径：走路时想到一个点子 → 记成灵感（10 秒）→ 周末翻一遍，标「可行」→ 点「安排到某一天」→ 它就成了那天的任务。想法不会烂在备忘录里。
注意。「安排到某一天」是复制成任务，原来那条小记还留着。想清理的话，可以接着点「删除这条小记」。

提醒：07:30 与 23:00

REMINDERS

日拾每天只提醒两次，都在你需要的时刻：

时间提醒内容
07:30今天的任务清单（含每周固定任务，带时间）；时间轴里截止前 7 天 / 5 天 / 2 天 / 当天的任务
23:00今天还没完成的任务；如果都做完了，就温柔地提醒你写今日复盘

两种提醒方式，用哪种？

App 内提醒（默认）

打开 App 或切回前台时检查，到点就弹通知；错过的时间点会在下次打开时补上。

缺点：App 被系统彻底关掉后不会响。

准点推送（推荐）

由云端服务器准时发出，App 完全关闭也能收到，时间误差一般在几十秒内。

需要在每台设备上各开一次，且必须先登录账号。

开启准点推送

  1. 确认这台设备上已经登录账号（齿轮里能看到自己的邮箱）。
  2. 齿轮 →「提醒」→ 点「开启准点推送」。
  3. 系统弹窗点「允许」。
  4. 看到「准点推送：已开启」就成了。iPhone、iPad、Mac 各做一次。
iPhone / iPad 必须「添加到主屏幕」后再开启。用 Safari 直接打开网页时，苹果不允许网页推送，设置里会显示「需先添加到主屏幕」。如果显示「通知被拒绝」，请到 iOS「设置 → 通知 → 日拾」里打开允许通知。
收不到？先查这三样：① 是否从主屏幕图标打开的；② 系统里日拾的通知是否允许；③ 是否开了专注模式 / 勿扰模式（会拦掉通知）。开了推送后，App 自己不会再重复弹同一条提醒，不会收到两遍。

多设备同步

SYNC

在 iPhone、iPad、Mac 上登录同一个账号，就能看到同一份数据。在手机上勾掉的任务，几秒钟后 iPad 上也是勾好的。

什么时候会自动同步

  • 每次修改后约 1.5 秒；
  • App 从后台回到前台时；
  • 网络恢复时；
  • App 开着时，每 60 秒一次。

想立刻同步，去齿轮里点「立即同步」。断网时可以照常写，联网后会自己补传。复盘照片跟着一起：每次同步完成后，没上传的照片会在后台补传，删掉的照片也会从云端清掉。

齿轮上的小圆点

灰色还没登录，数据只在本机
绿色已登录，同步正常
转圈正在同步
红色同步出错。点进去能看到原因（密码失效、网络问题等），点「立即同步」重试
同一件事在两台设备上都被改过：以最后一次修改为准。所以尽量不要两台设备同时改同一条任务、同一天的复盘。日常使用几乎碰不到，因为同步只差一两秒。
在同一台设备上换账号登录：本机会清掉上一个账号的本地缓存（云端数据还在，不会丢）。用原来的账号重新登录，数据会重新拉回来。

和朋友一起用

每个账号的数据互相独立，看不到彼此的清单和照片。朋友打开同一个网址、注册自己的账号即可。（注册人数有上限，具体见布置这个 App 的人给的说明。）

12

备份、恢复与账号

BACKUP & ACCOUNT

导出备份

齿轮 →「数据」→「导出备份」。会下载一个 日拾备份-2026-11-13.json 这样的文件，里面是你所有的任务、固定任务、小记和复盘文字，纯文本，可以用记事本打开看。

建议：换手机前、大改之前、每月一次，导出一份存到网盘或发给自己。

备份文件里没有照片。照片存在云端，换设备时登录同一个账号，打开复盘就会自动下载回来；只导入备份文件的话，那几天会只剩文字。

导入备份

齿轮 →「数据」→「导入备份」→ 选那个 .json 文件，看到「导入成功」就好了。导入是合并，不是覆盖：同一条记录以备份里的为准，备份里没有的东西不会被删掉。

账号相关的几件事

修改密码齿轮 →「修改密码」→ 输入两次新密码（至少 6 位）。之后各设备用新密码登录。
忘记密码登录页点「忘记密码？」，填注册时用的邮箱，会收到一封重置邮件。点邮件里的链接回到日拾就能设新密码。（收不到就看垃圾箱；这个功能需要布置者已配好邮件服务。）
退出登录齿轮 →「退出登录」。本机数据保留，但不再上传云端；重新登录后继续同步。退出前会提示你还有几条修改没上传。
注销账户齿轮最下面的「注销账户」。会永久删除云端的全部任务、固定任务、小记、复盘和照片，所有设备都找不回来，需要输入「注销」两个字确认。注销前请先导出备份，想留的照片先存到相册。
三重保险：文字数据平时在「本机 + 云端」各一份；重要时刻再加一份手动导出的 JSON。三者互不依赖。照片在「本机 + 云端」各一份。
数据存在哪里？一份在你设备的浏览器本地存储里，登录后另一份在云端数据库（按账号隔离，只有你自己的账号能读写）。照片存在云端的私密存储空间，同样只有你自己能看。手动导出的 JSON 只在你手上。

十个省时间的小技巧

TIPS
  1. 回车换行。编辑页在任务名里按回车，立刻多一行，一口气列完不用点按钮。
  2. 只填开始时间就够。「08:30 开会」比「08:30–09:00 开会」好写，排序一样准确。
  3. 点日期文字跳转。「今天」这两个字可以点，会弹出日期选择器，直接跳去下周三。
  4. 临时改动别动每周设置。用固定任务菜单里的「只改这一天」，历史记录才不会被牵连。
  5. 考试周用「暂停」。一次性把健身、社团都暂停两周，考完自动恢复，不用一个个删。
  6. 灵感变任务。小记里点「安排到某一天」，点子就有了执行日期。
  7. 休息日。出去玩那天点「设为休息日」，固定任务全部让路，回来不用一条条补。
  8. 从日历补记。想补写上周的复盘、补一张照片，从日历点那一格进去，比一直按 ‹ 快得多。
  9. 看星星找节奏。日历上 ★ 连成一片的那几周，翻回去看当时写了什么，通常就是你的高效配方。
  10. 深色模式跟随系统。iPad / Mac 宽屏时，导航会变成左侧竖栏，屏幕用得更满。
最后一条不算技巧：每天只写 3–6 件事。写满二十条的那种清单，第二天就不想打开了。

常见问题

FAQ

打开是白屏，或者还是旧样子

先下拉刷新。iPhone 上把日拾从后台完全关掉再打开一次；仍不行就检查网络（第一次加载需要联网，之后离线也能开）。

提醒不准时 / 收不到，能改时间吗

大概率是没开准点推送：按第 10 章开启，并确认是从主屏幕图标打开的。提醒时间固定为 07:30 和 23:00，页面内不能改；觉得太早或太晚，可在系统通知设置里把日拾静音或关闭。

看不到「📷 添加照片」 新

说明手机上还是旧版本。把日拾从后台完全关掉，再打开一两次就会更新到新版。

照片一直显示「☁︎ 待上传」，或在另一台设备上显示「未同步」 新

「待上传」：检查这台设备是否联网、是否已登录，联网打开日拾后会自动补传。「未同步」：照片还在原来那台设备上没传上来，等那台设备联网打开一次就好。

选照片时提示「这张图片打不开」 新

多半是 iPhone 的 HEIC 格式照片。在 iPhone 上用日拾选照片一般会自动转换；也可以在 iPhone「设置 → 相机 → 格式」选「兼容性最佳」，以后拍的照片就不会再遇到。

换手机了，数据怎么过去

新手机登录同一个账号，几秒后数据自动出现，照片打开时会自动下载；如果从没登录过，就在旧手机导出备份、新手机导入（照片不在备份里）。

两个人能用同一个账号吗

会看到彼此的清单和照片，不建议。每人注册一个账号，数据互不干扰。

固定任务改了，以前的日子怎么也跟着变了

正常不会变 —— 除非用了「修改以后的每周安排」并改了开始日期。只影响单天，请用「只改这一天」。

不小心删了任务，能找回吗

页面内没有撤销按钮。可用之前导出的备份导入恢复；或去另一台还没同步的设备上直接导出备份（先别让它同步）。
